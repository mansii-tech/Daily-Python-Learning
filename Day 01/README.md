# Python Variables and Data Types

## Description
This program demonstrates how to declare and initialize variables in Python to store student details such as roll number, name, fees, and active status. It also uses the `type()` function to check the data type of each variable.

## Concepts Covered
- Variable Declaration and Initialization
- Python Data Types
- Integer (`int`)
- String (`str`)
- Boolean (`bool`)
- Using the `print()` Function
- Checking Data Types Using `type()`

## Program Details
The program stores the following student information:

- **Roll Number:** 11
- **Name:** Mansi
- **Fees:** 1000000
- **Is Active:** True

It displays the student details and prints the data type of each variable.

## ▶️ Expected Output
```text
--student details--
Roll No. 11
Name mansi
Fees 1000000
is active True
<class 'int'>
<class 'str'>
<class 'int'>
<class 'bool'>
```

## Key Learning
The `type()` function in Python is used to identify the data type of a variable.
