# Python OOP Practice

## About
In this repository, I have practiced basic Object-Oriented Programming (OOP) concepts in Python. I solved these questions to improve my understanding of classes, objects, methods, constructors, and inheritance.

## Questions Covered

### Q1. Class and Object
- Created a `Student` class with `name` and `marks` attributes.
- Used the `display()` method to print student details.
- Created two objects and displayed their details.

### Q2. Methods with Calculation
- Created a `Rectangle` class with `length` and `width` attributes.
- Used the `area()` method to calculate the area.
- Used the `perimeter()` method to calculate the perimeter.

### Q3. Constructor with Default Value
- Created a `Counter` class with an initial count of `0`.
- Used `increment()` to increase the count.
- Used `decrement()` to decrease the count.
- Used `show()` to display the final count.

### Q4. Inheritance
- Created a parent class `Person` with `name` and `age` attributes.
- Created a child class `Student` that inherits from `Person`.
- Used `super()` to call the parent class constructor.
- Overrode the `display()` method to print student details.
