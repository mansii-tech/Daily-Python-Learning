# Python Variables, Type Conversion and User Input

In this program, I practiced different concepts of Python like changing variable types, declaring multiple variables in one line, type conversion, and taking input from the user.

## Concepts Covered

- **Changing Variable Type:** A variable can store different types of values during program execution.
- **Multiple Variable Assignment:** Assigning values to multiple variables in one line.
- **Type Conversion:** Converting string values into integer and float values using `int()` and `float()`.
- **Boolean Conversion:** Checking student status using user input.
- **User Input:** Taking input from the user using `input()`.
- **Split Method:** Accepting multiple values in a single line using `split()`.
- **F-Strings:** Displaying variables and results in a readable format.

## What I Learned

- How to change the value and data type of a variable.
- How to assign multiple values to different variables.
- How to convert string values into numeric values.
- How to accept input from the user.
- How to accept three numbers in one line and calculate their total.

## Technology Used

- Python 3
