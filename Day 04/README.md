# Python Conditional Statements – Practice Programs

In this program, I practiced Python `if`, `elif`, and `else` statements using different real-life examples. These programs helped me understand how to make decisions based on conditions.

## Programs Covered

### 1. Customer Segment
Classifies customers based on their total spending.

- Spend ≥ 50,000 → Premium
- Spend ≥ 20,000 → Gold
- Spend ≥ 5,000 → Silver
- Spend below 5,000 → Bronze

### 2. Leap Year Checker
Checks whether a given year is a leap year or not using divisibility rules.

### 3. Odd or Even Number
Checks whether a number is even or odd using the modulus (`%`) operator.

### 4. Positive, Negative or Zero
Checks whether a number is positive, negative, or zero.

### 5. Largest of Two Numbers
Compares two numbers and finds the larger number. If both numbers are equal, it displays a message.

## Concepts I Learned

- `if`, `elif`, and `else` statements
- Conditional statements in Python
- Comparison operators (`>=`, `>`, `<`, `==`)
- Modulus operator (`%`)
- Taking user input using `input()`
- Converting input into `int` and `float`
- Applying logical conditions to solve problems

## Technology Used

- Python 3

## What I Learned

Through these practice programs, I learned how to use conditional statements to solve basic problems and apply decision-making logic in Python.
